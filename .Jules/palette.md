## 2025-05-15 - Improving Form Accessibility and Interaction
**Learning:** Transforming non-semantic container-based forms into semantic HTML `<form>` elements provides several UX and accessibility "freebies": it enables standard "Enter to submit" keyboard behavior across all inputs, and allows the use of native browser validation (like the `required` attribute) which is more accessible and consistent for users than custom JS validation. Additionally, explicitly linking `<label>` elements to form controls via `id` and `for` attributes is critical for screen reader users and improves the clickable area for all users.
**Action:** Always prefer semantic `<form>` elements over `div` containers for user input, and ensure all labels are programmatically associated with their controls.

## 2026-04-30 - Semantic Forms and Native Validation
**Learning:** Converting div-based form containers to semantic <form> elements with a submit button enables essential browser features like 'Enter to submit' and native field validation. This significantly improves accessibility for keyboard users and provides immediate feedback without custom JavaScript.
**Action:** Always wrap interactive input groups in a <form> element and use the 'required' attribute for mandatory fields to leverage built-in browser UX.

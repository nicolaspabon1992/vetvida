## 2025-05-06 - Improve Form Accessibility and Usability
**Learning:** Converting generic div-based forms into semantic <form> elements with properly associated <label> elements and 'required' attributes significantly improves accessibility for screen readers and enables native browser validation. Adding a form reset after submission provides clear feedback to the user that their action was completed.
**Action:** Always use semantic <form> elements and associate labels with inputs using 'id' and 'for' attributes. Leverage native HTML validation for mandatory fields.

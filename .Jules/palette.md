## 2025-05-15 - Enhancing Accessibility in Single-Page Static HTML
**Learning:** In a static, vanilla JS project using `onclick` for navigation, accessibility can be significantly improved by shimming keyboard support globally. Using a single `keydown` listener for elements with `role="link"` or `onclick` attributes (while excluding native buttons/anchors) provides a scalable way to make custom UI components (like breadcrumbs or logos) keyboard-accessible without duplicating event listeners. Additionally, converting `div` containers to semantic `<form>` elements and passing `this` to the submission handler allows for native browser validation and easy form resetting.
**Action:** Always implement a global keyboard shim for custom interactive elements and leverage semantic `<form>` tags with `form.reset()` in projects relying on vanilla JavaScript for form handling.

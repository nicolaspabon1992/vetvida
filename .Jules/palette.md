## 2026-06-25 - Semantic Form Refactoring and Loading States
**Learning:** Refactoring div-based forms to semantic <form> elements with native validation (required, type) and simulated loading states (disabling button, text change) significantly improves accessibility (for/id labels) and provides immediate, intuitive user feedback in static sites.
**Action:** Always prefer semantic <form> structures and implement visual loading feedback for any asynchronous or simulated-async user actions.

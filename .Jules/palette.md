## 2026-03-03 - Form Accessibility and Async Submit State
**Learning:** In plain HTML forms, converting container `<div>` elements into proper `<form>` elements and linking `<label for="...">` to `<input id="...">` enables native keyboard form submissions and screen reader field identification.
**Action:** Ensure form controls are housed inside standard `<form>` elements with explicit label-input associations and asynchronous visual state management (e.g., button disablement during submit).

## 2026-04-25 - Semantic Forms and Native Validation
**Learning:** Even in single-page static sites using JavaScript for navigation and submission, using a semantic `<form>` element with the `required` attribute and `onsubmit` handler provides significant UX benefits: native validation tooltips, "Enter" key submission, and better accessibility for screen readers.
**Action:** Always prefer semantic `<form>` over `div` for interactive data entry, and utilize native HTML5 validation attributes before reaching for custom JS validation.

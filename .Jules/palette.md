## 2026-07-17 - Actionable Contact Information
**Learning:** In static sites, providing direct `tel:`, `mailto:`, and `https://wa.me/` links for contact information significantly improves the user experience, especially on mobile devices. Using inline styles for micro-UX improvements can help stay within line limits and avoid adding unnecessary CSS classes when the changes are highly localized.
**Action:** Always check if contact details are clickable and use semantic `<a>` tags with appropriate protocol handlers.

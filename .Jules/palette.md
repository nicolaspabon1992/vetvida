## 2025-05-14 - Semantic Form Conversion
**Learning:** Converting `div`-based forms to semantic `<form>` elements with `id`/`for` label associations and `required` attributes provides immediate UX wins: native browser validation, "Enter to submit" support, and programmatically associated labels for screen readers.
**Action:** Always wrap interactive input groups in a `<form>` element and ensure every input has a corresponding `<label for="...">` to maximize accessibility and native browser functionality.

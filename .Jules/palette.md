# Palette UX Journal

## 2025-05-14 - Accessible Semantic Forms
**Learning:** Converting `div`-based forms to semantic `<form>` elements with proper label-input associations and native validation (`required`, `type`) significantly improves both accessibility (screen readers, keyboard navigation) and usability (Enter to submit, clear error feedback).
**Action:** Always use `<form>`, `<label for="...">`, and `<button type="submit">` for interactive data entry sections.

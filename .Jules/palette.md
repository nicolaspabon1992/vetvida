## 2026-08-02 - [Keyboard Accessibility for Dynamic SPAs]
**Learning:** In static single-page apps where navigation and interactive toggles are handled dynamically via JS (e.g., onclick handlers on generic element containers like mock <a> links without href or <div> elements), standard keyboard navigation is completely broken by default. Simply adding tabindex="0" makes elements focusable, but fails to trigger activation on Enter/Space keypresses without explicit event handlers. Specifying correct semantic roles (role="link" or role="button") and aria-expanded states, backed by a global keydown event listener to translate Enter/Space keypresses to clicks, restores perfect keyboard and screen reader accessibility.
**Action:** When working on dynamic SPAs with custom click behaviors, always enhance interactive components with role, tabindex, and aria-expanded attributes, and integrate a global Enter/Space keydown listener to trigger clicks.

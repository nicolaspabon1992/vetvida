## 2026-05-12 - Semantic Form Refactoring for Accessibility and Usability
**Learning:** Converting div-based forms to semantic <form> elements with proper label associations (id/for) and native validation (required) significantly improves the user experience. It enables built-in browser features like "Enter to submit" and native validation tooltips, while ensuring the interface is accessible to screen readers and keyboard users.
**Action:** Always prefer semantic <form> elements over generic containers for user input, and ensure every input has a clearly associated label.

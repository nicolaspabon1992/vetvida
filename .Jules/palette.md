## 2025-05-13 - Semantic Form Refactoring for Accessibility and Usability
**Learning:** Converting `div` or generic containers to semantic `<form>` elements, combined with proper `<label>` associations and `required` attributes, leverages native browser validation and improves accessibility for screen readers and keyboard users (e.g., "Enter to submit").
**Action:** Always prefer semantic `<form>` tags over generic containers for user inputs, and ensure each field has a dedicated ID and corresponding label.

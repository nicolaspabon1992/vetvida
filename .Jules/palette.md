## 2026-06-11 - Actionable Emergency Contacts & Semantic Forms

**Learning:** Converting non-functional buttons to actionable links (like `tel:`) and refactoring div-based forms to semantic `<form>` elements significantly improves accessibility and provides a more intuitive experience for mobile and screen-reader users. Native validation attributes (`required`) and immediate visual feedback (loading states) create a smoother interaction.

**Action:** Always use semantic elements for interactive components. For forms, use `<form>` with native validation and provide visual feedback for asynchronous actions (simulated or real). Ensure emergency contacts are actionable via appropriate URIs.

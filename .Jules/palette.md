
## 2026-05-19 - Semantic Contact Form with Feedback
**Learning:** Refactoring div-based forms to semantic <form> elements with native validation attributes (required, type) and explicit label associations (for/id) significantly improves accessibility and usability. Adding a simulated loading state (disabling the button and changing text) provides immediate, clear feedback for asynchronous-like operations in a static site.
**Action:** Always prefer semantic <form> elements and ensure interactive elements provide visual feedback during state changes (like 'Enviando...').

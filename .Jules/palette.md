## 2026-07-28 - Semantic Refactoring and Submission Feedback on Contact Forms
**Learning:** Refactoring forms to be fully semantic (using a `<form>` element with properly mapped `<label>` and `<input>` associations) not only unlocks native HTML5 validation and screen reader support, but also enables cohesive programmatic control over submission lifecycle events. Integrating an async loading feedback loop—such as disabling the submit button and showing a clear "Enviando..." transition—is critical to preventing accidental duplicate submissions and providing immediate visual confirmation to the user.
**Action:** Always wrap input fields within a `<form>` container, use exact `for` and `id` bindings for accessible labeling, and wrap simulated asynchronous actions in robust `try...finally` blocks to guarantee form reset and interactive element state restoration under all circumstances.

## 2026-06-19 - Semantic Form Refactoring and Loading States
**Learning:** Refactoring div-based forms to semantic <form> elements with native validation attributes (required, type="tel", etc.) significantly improves accessibility and provides free browser-level validation. Adding a simulated loading state (disabling the button and changing text) provides immediate, clear feedback to the user, even in static sites.
**Action:** Always use semantic <form> elements and include visual feedback for submission states.

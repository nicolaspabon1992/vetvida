## 2025-05-15 - Improving SPA Accessibility and Mobile Interaction
**Learning:** For single-page applications (SPAs) that use `onclick` for navigation, user experience is significantly enhanced by providing functional links for contact info (tel:, mailto:, maps) and ensuring keyboard focus states (:focus-visible) are distinct. Additionally, when refactoring div-based interactive elements into accessible ones, nested buttons should be removed to avoid focus traps and maintain a clean tab order.
**Action:** Always use `:focus-visible` for keyboard navigation and convert static contact text into actionable links. Ensure `role="link"` or `role="button"` elements have `tabindex="0"` and handle `Enter` key events. Avoid accidental translations when editing content in different languages.

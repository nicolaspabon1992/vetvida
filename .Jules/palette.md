## 2025-05-14 - Semantic Form Accessibility
**Learning:** Using a semantic `<form>` element instead of a generic `<div>` for form containers enables native browser features like 'Enter to submit' and built-in validation (e.g., `required` attribute), providing a more robust and accessible user experience with minimal code.
**Action:** Always wrap interactive input groups in a `<form>` element and ensure all labels are explicitly associated with their inputs using `for` and `id` attributes.

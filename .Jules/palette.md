## 2026-07-17 - Semantic form refactoring with visual loading feedback
**Learning:** Legacy layouts of static forms in VetVida heavily rely on precise nested classes like `.form-row` and `.form-group` for layout grid/flex alignment. Simply wrapping div elements inside a `<form>` container and maintaining the original inline structure preserves the styling while enabling rich native features like client-side required validation and keyboard form submission. Adding an async loading state via button disabling prevents duplicate form submissions and provides immediate feedback.
**Action:** When refactoring legacy forms, always preserve the existing class hierarchy and layouts exactly while converting container wrappers to semantic elements. Implement async submission wrappers with state-restoring try/finally blocks to ensure UI controls never get stuck in a disabled state if errors occur.

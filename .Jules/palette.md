## 2026-07-30 - Actionable Contact Options and Semantic Keyboard Navigation
**Learning:** In static single-page apps, navigation links are often implemented using div/span elements or `<a>` elements without an `href` attribute. This completely strips them of native keyboard focusability (Tab index) and screen reader identification. Additionally, leaving emergency call-to-actions, phone numbers, and location details as plain, inert text on the page forces mobile and desktop users to manually copy-paste during urgent situations, creating major usability friction.
**Action:** Always verify that navigation tags use proper `href="#"` and return `false` on click to retain keyboard focusability natively, and wrap critical contact info in actionable links (`tel:`, `https://wa.me/`, `mailto:`, Google Maps query) so they are directly interactive.

## 2025-05-15 - Semantic Contact Forms and Native Validation
**Learning:** In the VetVida project, contact forms were originally implemented using non-semantic `div` containers and custom JavaScript handlers without native browser validation. This prevents 'Enter to submit' behavior and requires manual validation logic. Converting these to semantic `<form>` elements with `required` attributes and properly associated `<label>` elements significantly improves accessibility and user intuition.
**Action:** Always use `<form>` for user inputs. Ensure every input has a corresponding `<label>` with a matching `id`. Use the `required` attribute and a default empty `<option>` for selects to leverage native browser validation. Update the submission handler to accept the form element (e.g., `onsubmit="submitForm(this)"`) to easily call `form.reset()` for clear user feedback after successful submission.

## 2026-07-08 - Semantic Form Refactoring and Loading Feedback
**Learning:** Refactoring <div>-based forms to semantic <form> elements with explicitly associated labels (for/id) significantly improves accessibility for screen readers and enables native browser validation. Adding a simulated loading state (disabling the button and updating text) provides immediate, clear feedback for asynchronous operations in static sites.
**Action:** Always use semantic <form> tags and ensure all inputs have linked labels. Implement visual loading states for any action that takes time to complete.

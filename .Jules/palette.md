## 2025-05-14 - Form Accessibility and Keyboard Visibility
**Learning:** In static, single-page applications using vanilla JavaScript for navigation, generic `div` elements are often used for forms. Converting these to semantic `<form>` elements and using the `onsubmit` event (with `event.preventDefault()`) enables native browser features like 'Enter to submit' and field validation (`required`) without breaking the custom navigation. Additionally, a global `:focus-visible` style ensures that keyboard users have a consistent and high-contrast way to track their location on the page.
**Action:** Always prioritize semantic HTML for interactive components. For any form, use `<form>`, `<label for="...">`, and `<input id="...">` to ensure accessibility and better UX through native validation. Implement `:focus-visible` to provide accessible focus states that match the app's brand.

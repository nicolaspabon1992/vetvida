## 2026-08-11 - Semantic Booking Form & Submission Feedback
**Learning:** Using non-semantic layouts (e.g. `div` tags) instead of `<form>` prevents native browser form validations, breaks input label associations, and degrades keyboard accessibility. Linking labels explicitly using standard HTML `for` and `id` attributes ensures screen readers correctly announce form elements. Furthermore, disabling the submit button and showing a clear "Enviando..." loading state inside a `try...finally` block provides critical feedback to the user, preventing multiple submissions and accidental page reloads.
**Action:** Always wrap form inputs in a semantic `<form>` element, map `<label>` to `<input>`/`<select>`/`<textarea>` with standard `for` and `id` tags, apply native `required` fields, and utilize a robust async submission handler with try-finally button states and transition styles.

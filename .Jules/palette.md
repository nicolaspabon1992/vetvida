## 2026-07-05 - Semantic form refactoring with visual feedback
**Learning:** Converting div-based forms to semantic <form> elements with native validation and explicit labels significantly improves accessibility. Adding a simulated loading state (disabling button, changing text) provides immediate UX feedback in static sites.
**Action:** Use <form> with onsubmit, associate labels via for/id, and implement button loading states for all interactive forms.
